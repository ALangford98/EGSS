# File Tree Panel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Browse and open any file in the currently open project from a new dock panel, instead of typing a path by hand.

**Architecture:** A new panel walks `std::filesystem` live each frame, rooted at the already-existing `g_EditorProjectPath`. No tree-mirroring state — ImGui's own `TreeNode` persists expand/collapse per-ID. Clicking a file forwards its path into the text editor's existing load logic, factored out into a small public method.

**Tech Stack:** C++17, `std::filesystem` (already used elsewhere in this codebase), ImGui (already vendored).

**Spec:** `docs/superpowers/specs/2026-09-10-file-tree-design.md`

- [ ] **Step 1: Write `FileTreePanel.h`**

```cpp
#pragma once

// Browses the currently open project's files. No persistent tree state --
// walks std::filesystem fresh each frame; ImGui's own TreeNode tracks
// open/closed state per-ID (persisted via imgui.ini), so there's nothing
// to keep in sync with the real filesystem.

#include <GS.h>
#include <imgui.h>

#include "EditorProject.h"

#include <algorithm>
#include <filesystem>
#include <string>
#include <vector>

class FileTreePanel
{
public:
	// Returns the path of a file the user clicked this frame, or an empty
	// string if nothing was clicked.
	std::string OnImGuiRender()
	{
		std::string clicked;

		ImGui::Begin("Files");

		if (g_EditorProjectPath.empty())
			ImGui::TextDisabled("Open or create a project to browse its files.");
		else
			DrawDirectory(g_EditorProjectPath, clicked);

		ImGui::End();
		return clicked;
	}

private:
	void DrawDirectory(const std::filesystem::path& dir, std::string& clicked)
	{
		std::error_code ec;
		std::vector<std::filesystem::directory_entry> entries;
		for (const auto& entry : std::filesystem::directory_iterator(dir, ec))
		{
			std::string name = entry.path().filename().string();
			if (!name.empty() && name[0] != '.')
				entries.push_back(entry);
		}

		std::sort(entries.begin(), entries.end(), [](const auto& a, const auto& b) {
			if (a.is_directory() != b.is_directory())
				return a.is_directory(); // directories before files
			return a.path().filename().string() < b.path().filename().string();
		});

		for (const auto& entry : entries)
		{
			std::string name = entry.path().filename().string();
			if (entry.is_directory())
			{
				if (ImGui::TreeNode(name.c_str()))
				{
					DrawDirectory(entry.path(), clicked);
					ImGui::TreePop();
				}
			}
			else
			{
				if (ImGui::Selectable(name.c_str()))
					clicked = entry.path().string();
			}
		}
	}
};
```
